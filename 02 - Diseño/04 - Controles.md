# Controles

## Descripción de la sección

Define la relación entre las acciones del jugador y las entradas físicas del dispositivo.

## Mapa de controles

| Acción            | Teclado | Mouse          | Control | Táctil |
| ----------------- | ------- | -------------- | ------- | ------ |
| Mover             | W,A,S,D |                |         |        |
| Interactuar       | F       |                |         |        |
| Ataque principal  |         | Clic izquierdo |         |        |
| Ataque secundario | E       | Clic derecho   |         |        |
| Saltar            |         |                |         |        |
| Menú              | ESC     |                |         |        |

## Principios de control

- Los controles deben ser consistentes.
- Las acciones críticas deben ser fáciles de identificar.
- Debe existir retroalimentación visual, sonora o háptica cuando corresponda.
- Evitar combinaciones innecesariamente complejas.

## Reasignación

¿El jugador puede cambiar los controles?
No. En la versión base de entrega escolar, los controles se mantendrán fijos bajo la distribución estándar WASD + Mouse para garantizar la estabilidad técnica.
## Entrada y retroalimentación

Describe qué ocurre inmediatamente después de cada entrada importante.
 
 - Clic Izquierdo -> Efecto de sonido de disparo, consumo de 1 bala en la interfaz y proyectil viajando en pantalla.

- Clic Derecho -> Animación de corte en arco frontal y sonido de blando/impacto.

- Espacio -> Sprite del escudo desplegado o Deslizamiento rápido con rastro de sombra.

- Tecla 1 / 2 ->  Actualización instantánea en la barra de salud.

- Tecla F -> Sonido de recolección, icono de tarjeta y apertura de puerta.
