# Público y Plataforma

## Descripción de la sección

Define para quién se diseña el videojuego y dónde se jugará. Las decisiones de diseño, interfaz, controles y rendimiento dependen de estas variables.

## Público objetivo

**Edad aproximada:**
18-25 años
**Experiencia esperada:**  
Intermedia
> Casual, intermedia, avanzada.

**Intereses relevantes:**
Juego de supervivencia y acción junto con suspenso y estrategia para aguantar y llegar hasta el final
**Conocimientos previos necesarios:**
Conocimiento en uso ágil de las teclas de movimiento como los son WASD y uso del ratón para apuntar a los enemigos.
## Plataforma

| Elemento                | Decisión            |
| ----------------------- | ------------------- |
| Plataforma principal    | PC                  |
| Plataformas secundarias |                     |
| Método de entrada       | Teclado / Mouse     |
| Resolución objetivo     | Full HD (1920x1080) |
| Relación de aspecto     | 16:9                |
| Rendimiento objetivo    | 60 FPS              |
| Conexión requerida      | No                  |

## Restricciones de plataforma

Documenta limitaciones de hardware, controles, memoria, almacenamiento, distribución o conectividad.

## Sesión de juego

**Duración esperada de una sesión:**
5 a 10 minutos
**Duración total estimada del juego:**
25 minutos
## Modelo de distribución
Prototipo Académico

> Gratuito, pago único, educativo, prototipo académico, etc.
